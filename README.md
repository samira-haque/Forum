## 📖 Overview

Forum is a web-based discussion platform designed to facilitate communication, collaboration, and knowledge sharing among users. The application allows users to create discussion topics, post comments, engage in conversations, and interact within an organized online community.

This project demonstrates the implementation of web development concepts including user authentication, database management, session handling, and dynamic content rendering using PHP and MySQL.

---

## 🎯 Project Goals

- Create an interactive online discussion platform.
- Enable users to share knowledge and ideas.
- Provide a structured communication environment.
- Demonstrate full-stack web development concepts.
- Implement secure user authentication and forum management.

## 🚀 Getting Started

### Prerequisites

Make sure the following software is installed:

- PHP 7.4+
- MySQL
- Apache Server
- XAMPP / WAMP / LAMP

---

## 📥 Installation

### Clone the Repository

```bash
git clone https://github.com/samira-haque/Forum.git
```

### Move to Server Directory

For XAMPP:

```text
xampp/htdocs/Forum
```

For WAMP:

```text
wamp/www/Forum
```

---

## 🗄 Database Setup

### Create Database

```sql
CREATE DATABASE forum_db;
```

### Import Database

Import the provided SQL file:

```text
database.sql
```

### Configure Database Connection

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "forum_db";
```
